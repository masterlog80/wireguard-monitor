Peer View

Each peer's Throughput chart on the Dashboard shows RX/TX from the server's point of view by default — RX is what the server received from that peer, TX is what the server sent to it. Enable "Peer view" below for any peer to show its chart from that peer's own point of view instead (its RX = what it received = what the server sent). This only changes the labeling of the chart on the Dashboard — the underlying data is unaffected.
